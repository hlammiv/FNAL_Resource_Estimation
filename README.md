# FNAL Resource Estimation

Resource models behind the Fermilab whitepaper *A Program for Scientific Quantum Utility at Fermilab* (2026). Every logical-qubit count, T-gate count, shot count and wall time printed in the paper's benchmark boxes and in its summary table is generated by the code here, from assumptions that carry their provenance (a citation, an explicit assumption, or a number stated by the paper and not derived).

This repository holds the code only; the paper is not included. Chapters 11 (qudit platforms) and 12 (dark-matter sensing) are parametric models in the paper and are not part of this package.

## Layout

```
estimates/            the package: one model per application, shared conventions, tests
  common.py           rotation synthesis, Toffoli and wall-time conventions, provenance tags
  groups.py           gauge-group primitives (qubits per link, plaquette and group-action T-counts)
  chNN_*.py           the per-application models (Chapters 2-10 of the paper)
  tests/              pytest suite pinning every published number
  __main__.py         command-line entry point
docs/                 CONTRACT.md (the model contract), CIRCUIT_STATUS.md (per primitive:
                      compiled / scaling argument / conjecture / unsourced), PAPER_COSTS.md
resources.json        the generated numbers, as the paper's figures and table consume them
```

## Running

```
python -m estimates                 # every instance: qubits, T-count with its breakdown, shots
python -m estimates --resources     # regenerate resources.json
python -m estimates --status        # regenerate docs/CIRCUIT_STATUS.md
python -m pytest estimates/tests -q
```

Only the standard library and `numpy` are needed. Some tests check that the paper's chapter text quotes the model's numbers; without the paper source alongside they skip.

## Conventions shared by every model

- Logical qubits count the algorithmic register only; magic-state factories are excluded.
- Toffoli gates are priced at 7 T. Every rotation is priced at the full synthesis fit, 1.15 log2(1/ε) + 9.2 T, with ε set per circuit from its own rotation count so that the total rotation error stays at 1%.
- The fault budget is 0.1 expected faults per circuit, which fixes the required logical error rate.
- Wall times are for one machine: 1 µs per T plus 0.1 ms per shot, about ten magic-state factories. Nothing assumes several machines.
- Two tiers are quoted: a first result at 30% precision and a campaign at the target precision.
- The DOE reference budgets (150-250 logical qubits and 10^5 T in 2028; about 1000 logical qubits and 10^9 T in 2033) are comparison points, not limits.

## Status

The package and its tests are complete and are the paper's source of truth. Per-application READMEs under `applications/` (what each model estimates, its assumptions with provenance, how the numbers are built, open items) are in preparation.
