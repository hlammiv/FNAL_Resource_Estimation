# Chapter 7: quantum fields in curved spacetime (reheating)

Model: [`estimates/ch07_curved_space.py`](../../estimates/ch07_curved_space.py).
Tests: [`estimates/tests/test_ch07_curved_space.py`](../../estimates/tests/test_ch07_curved_space.py).
Chapter text: `applications/app04_curved_space.tex` in the paper source (not in this repository).

## 1. What is estimated

The chapter simulates particle production by an expanding FLRW background, $ds^2 = -dt^2 + a(t)^2 d\vec x^2$, on a cubic lattice. A real scalar is digitized on a uniform $K$-point field-amplitude grid per site (Macridin et al., arXiv:2108.10793), so it takes $n_q = \log_2 K$ qubits per site; a Wilson fermion takes 4 qubits per site in a Jordan-Wigner encoding. Time evolution is a symmetric second-order (Stormer-Verlet) Trotter product with the Hamiltonian evaluated at the step midpoint, using the term circuits of Li, Macridin, Mrenna and Spentzouris (arXiv:2210.07985, Sec. III.C). The observable is the out-state occupation $\langle n_k\rangle$ per momentum shell, read from equal-time two-point functions measured in a few fixed computational-basis settings.

Each era's headline numbers are printed in a summary box in the chapter ("the box" below). Two instances are costed. There is no co-design row (`model(a, "codesign")` raises).

| era | instance | lattice and fields | state preparation | target |
|---|---|---|---|---|
| 2028 benchmark | free scalar in de Sitter | $4^3$ (64 sites), $K=8$ (3 qubits/site), no fermion, no $\phi^4$ | Gaussian-network Bunch-Davies vacuum | one midpoint Trotter step, IR-shell two-point functions to ~5%, checked against the same one-step map |
| 2033 target | $\phi^4$ scalar + one Wilson fermion, low-occupation preheating | $5^3$ (125 sites), $K=16$ (4 qubits/site) + 4 fermion qubits/site | adiabatic switch-on of the couplings over $5/H_{\rm inf}$, then a condensate boost $e^{i\bar\pi\sum_x\phi_x}$ | fermion $\langle n_k\rangle$ at 30% (first result, one $a(t)$ profile) and 10% per shell (campaign, 10-20 profiles) |

The 2033 run evolves for $T_{\rm phys} = 10/H_{\rm inf}$ at $\Delta t = 5\times10^{-4}/H_{\rm inf}$, i.e. $m_\phi \Delta t = 0.05$ with $m_\phi \sim 10^2 H_{\rm inf}$, under a prescribed matter-like background $a(t) = (1 + 1.5 H t)^{2/3}$.

## 2. How to run

From the repository root:

```
python -m estimates --chapter ch07                  # assumptions, resources.json rows, exports, breakdown
python -m estimates --chapter ch07 --intermediates  # also every named intermediate the model records
python -m pytest estimates/tests/test_ch07_curved_space.py -q
python applications/ch07_curved_space/dump_assumptions.py   # the tables in Section 3
```

`--chapter ch07` prints three blocks. ASSUMPTIONS lists the 87 inputs with value, provenance tag and source. INSTANCES shows the two rows the chapter writes to `resources.json`. EXPORTS gives, per era, the headline logical qubits and T count against the box as printed (`[ok]` when inside the 10% tolerance), shots, wall time, $\epsilon_l$, the T-depth and factory keys, and the primitive-by-primitive T breakdown with its circuit status; under each era the model's notes follow, one line per arithmetic step. The command is read-only.

The chapter test file gives 52 passed, 1 skipped (run with `OMP_NUM_THREADS=2`, about 20 s). The skip and several conditional asserts inside other tests compare against the chapter `.tex`, which is not in this repository; they run only in the paper tree. The validation functions (`exact_reduced_step`, `ds2028_grid_check`, `twopi_lo`), and the tests that call them, need numpy and scipy; the cost model itself is pure Python.

## 3. Assumptions

Generated by `dump_assumptions.py` from the live `Assumptions` dataclass (lines 186-450 of the model), one table per section of the class body. The value column is the stored Python value; a tuple is a (low, high) band. Provenance is one of Cited (a published source or a report-wide ruling gives the value) or Assumed (a working assumption of the model, often the output of one of its own numerical checks, named in the source column). The third tag is Stated-not-derived (the chapter states it without derivation). An `app04:N` tag is the chapter location the model records; these tags are not kept in step with the current line numbers of the `.tex`. Sources named as files (`TRACKED_CHANGES.md`, `shot_audit.json`, `factory.json`, `editorial_review/...`) are in the paper's working tree, not in this repository. Sources named as functions (`verlet_proxy`, `exact_reduced_step`, `ds2028_grid_check`, `twopi_lo`, ...) are in the model and are rerun by the tests. The notes are printed verbatim from the code, so they keep the model's own record of where each value came from, including the dates of the rulings and the values they replaced.

Not every field enters the T count. The cost inputs are the lattice and field content, the per-term circuit inputs, the ancilla registers, the time-stepping fields named in Section 4, and the shot and timing fields. The `grid_2028_*`, `map_vs_desitter_*`, `twopi_lo_*`, `*_step_err_*` and `fixed_grid_*` fields record the results of the accuracy checks that justify the grid and step choices; the model and tests use them as guards and cross-checks, and changing them moves no printed cost.

## 4. How the numbers are built

All figures below are printed by `python -m estimates --chapter ch07 --intermediates`; the intermediate keys are named in parentheses.

### Register (`register`, lines 465-478)

$N_q = V(\lceil\log_2 K\rceil + 4N_f) + N_{\rm anc} + N_{\rm Had}$, with $N_{\rm anc} = 30$-$50$ (Stated) and no Hadamard-test qubit, since every observable is an equal-time two-point function read by direct measurement.

- 2028: $64 \times 3 = 192$ system qubits, 222-242 in all (`lq_sum`). The box prints 220-240.
- 2033: $125 \times (4 + 4) = 1000$ system qubits, 1030-1050 (`lq_sum`). The box prints 1050.

### Term counts for one Trotter step (`step_terms`, lines 518-546)

Because $\phi_j$ is linear in the $n_q$ Pauli-$Z$ operators of site $j$, every diagonal term is a sum of $Z$-strings, each one synthesized rotation:

| block | term | rotations | 2028 ($n_q=3$) | 2033 ($n_q=4$) |
|---|---|---|---|---|
| D (diagonal) | $\phi^2$ (+ mass, on-site gradient) and $\phi^4$ | $\binom{n_q}{2} + \binom{n_q}{4}$ per site | 3 | 7 |
| D | gradient $\phi_j\phi_l$ | $n_q^2$ per link, $3V$ links | 9 | 16 |
| D | Wilson mass + Yukawa $g\phi\bar\psi\psi$ | $4 + 4n_q$ per site per flavor | 0 | 20 |
| B (kinetic) | $\pi^2$ in the conjugate basis | $\binom{n_q}{2}$ per site | 3 | 6 |
| C (hop) | Wilson hop, 8 nonzero entries of $\gamma^0(r-\gamma_i)$ (checked by `wilson_hop_nonzeros`, lines 485-499) x 2 JW Pauli strings | 16 per link | 0 | 16 |
| QFT pair around B | per site, $n_q-1$ controlled-$S$ at 3 T each, and $\binom{n_q}{2}-(n_q-1)$ smaller controlled phases at 3 synthesized $R_z$ each, x 2 (QFT and inverse) | | 384 rot + 256 c-S | 2250 rot + 750 c-S |

Totals per block application (`diag_block_rotations`, `pi2_block_rotations`, `hop_block_rotations`, `qft_pair_rotations`): 2028 has D = $64\cdot3 + 192\cdot9 = 1920$ and B = 192. 2033 has D = $125\cdot7 + 375\cdot16 + 125\cdot20 = 9375$, B = 750 and C = $375\cdot16 = 6000$.

The centered transform $F = R_z \cdot {\rm QFT} \cdot R_z$ has two $R_z$ layers per site (`centering_layer`, lines 502-515). Angles at multiples of $\pi/2$ are Clifford, odd multiples of $\pi/4$ cost one T, the rest are synthesized. The layers cancel between consecutive $\pi^2$ blocks, so a shot carries two of them: 128 rotations + 128 T at 2028, 500 rotations + 250 T at 2033.

### From one step to one shot (`shot_counts`, lines 549-573)

- 2028 has no hopping block, so the step is $B/2\,D\,B/2$ with B outermost. For $n$ steps: D $\times n$, B $\times (n+1)$, QFT pairs $\times (n+1)$.
- 2033 has a hop, so the step is $D/2\,[C\,B\,C]\,D/2$ with D outermost and merged across steps. For $n$ steps: D $\times (n+1)$, B $\times n$, C $\times 2n$, QFT pairs $\times n$. Applying every hop string twice overcounts the middle group by less than 1%.

All synthesized rotations in one shot share one tolerance under the report-wide R-TOL rule: $\epsilon_{\rm rot} = \sqrt{10^{-2}/N_{\rm rot}}$, priced at $1.15\log_2(1/\epsilon_{\rm rot}) + 9.2$ T (`common.eps_rot_for`, `common.t_per_rotation`). Because $N_{\rm rot}$ counts the whole shot, a longer run also pays more per rotation.

### 2028 benchmark (`_model_2028`, lines 631-769)

1. One macro-step (`n_steps_2028` = 1). The loop at lines 643-649 counts how many steps fit under the $10^5$ cap together with the preparation: one fits (94,753 T); two would be 147,456 T (`shot_t_at_n_steps`).
2. $N_{\rm rot} = 1920 + 2\cdot192 + 2\cdot384 + 128 = 3200$ (`n_rot_per_shot`), so $\epsilon_{\rm rot} = 1.77\times10^{-3}$ at 19.72 T per rotation (`eps_rot`, `t_per_rotation`).
3. Evolution: $3200 \times 19.72 + 512 \times 3$ (controlled-S) $+ 128$ (centering T) $= 64{,}753$ T (`t_evolution`).
4. Preparation: 30,000 T for the Gaussian-network vacuum (`t_prep_2028`, Stated). This is the chapter's ~150 T per system qubit scaled to 192 qubits (`t_prep_per_system_qubit` = 156.25).
5. Per shot: 94,753 T (`t_per_shot`), 0.948 of the cap (`ratio_to_cap`).
6. Shots: 3 readout settings (field, conjugate and sheared field basis), which give the full $(\phi_k,\pi_k)$ covariance. 5% on the lowest shell needs $1/0.05^2 = 400$ samples, and that shell holds 3 complex modes, so at least 134 shots per setting (`shots_min_per_setting`). The model takes 150, giving 450 shots (`shots`). The settings reuse the last $\pi^2$ half-step and add no T (`readout_extra_t` = 0).
7. Wall time on one machine: $450 \times (94{,}753 \times 1\,\mu{\rm s} + 0.1\,{\rm ms}) = 42.68$ s (`wall_time_s`).
8. Error rate: at the RFI $\epsilon_l = 10^{-8}$ a shot carries $9.5\times10^{-4}$ expected faults (`expected_faults_at_rfi`). The box therefore quotes the RFI figure, and `epsilon_l` is exported as None.
9. Depth: T-depth 346-1308 (`t_depth_2028`, from the factory scheduler), giving $F^* = N_T/D_T = 72$-$274$ (`f_star`). That is at least the 10 factories behind the 1 µs/T convention, so no depth correction applies.

### 2033 target (`_model_2033`, lines 772-1047)

1. Steps: $T_{\rm phys}/\Delta t = 10/(5\times10^{-4}) = 2\times10^4$ evolution steps (`n_trotter_steps_net`; no commutator lever). The ramp adds $5/0.01 = 500$ switch-on steps of the same Hamiltonian (`n_prep_steps`), for 20,500 in one product. The condensate boost adds $125 \times 4 = 500$ single-$Z$ rotations, once (`condensate_boost_rotations`).
2. $N_{\rm rot} = 20501\cdot9375 + 20500\cdot(750 + 2\cdot6000 + 2250) + 500 + 500 = 499{,}697{,}875$ (`n_rot_per_shot`), so $\epsilon_{\rm rot} = 4.47\times10^{-6}$ at 29.64 T per rotation.
3. One step: $24{,}375$ rotations $\times\, 29.64 + 750 \times 3 = 7.246\times10^5$ T (`per_step_rotations`, `t_per_step`).
4. Per shot (`t_per_shot`): evolution $2\times10^4 \times 7.246\times10^5 = 1.449\times10^{10}$ (`t_evolution_net`), ramp $500 \times 7.246\times10^5 = 3.62\times10^8$ (`t_prep`, 2.5% of the evolution), boost $1.48\times10^4$ (`t_condensate_boost`), and closing D block plus centering layers $2.93\times10^5$ (`t_closing`). The total is $1.4855\times10^{10}$ T, 14.9 times the $10^9$ reference budget (`ratio_to_ceiling`).
5. Where the T goes (primitive breakdown): Wilson hop 49.1%, diagonal $Z$-strings 38.3%, QFT small controlled phases 9.2%, $\pi^2$ rotations 3.1%, controlled-S 0.3%. The centering layers and the boost together are about $3\times10^4$ T.
6. Shots per profile: $N = N_{\rm set}\,((n+\tfrac12)/n)^2/(m'\epsilon^2)$ with $N_{\rm set} = 2$, $n = 1$ and $m' = 3$ complex modes in the smallest shell (lines 793-804). This gives 16.67 at 30%, so 17-34 with the 1-2x margin (`shots_per_profile_first`), and 150 at 10%, so 150-300 (`shots_per_profile_campaign`). First result: one profile, 17-34 shots. Campaign: 10-20 profiles, 1500-6000 shots (`shots_campaign`).
7. Wall time on one machine: one shot is $1.4855\times10^{10} \times 1\,\mu{\rm s} + 0.1$ ms $= 1.4855\times10^4$ s, 4.13 h (`t_shot_s`). The first result takes 2.92-5.85 days (`wall_first_result_d`). The campaign takes 0.706-2.82 yr (`wall_campaign_yr`), inside the 5-year horizon (`campaign_fits_horizon`).
8. Error rate: 0.1 expected faults per shot in the T gates gives $\epsilon_l = 0.1/N_T = 6.73\times10^{-12}$ (`eps_l`), printed as $\lesssim 7\times10^{-12}$. At the RFI $10^{-8}$ a shot would carry 148.6 expected faults (`expected_faults_at_rfi`).
9. Depth: 27-92 rotation layers per step (`t_depth_layers_per_step_2033`, from the factory scheduler) $\times\, 29.64 \times 20{,}500$ gives a T-depth of $1.64$-$5.59\times10^7$. That makes $F^* = 266$-$906$, and 7.1-28.2 factories would finish the campaign in a year (`factories_for_1yr`), which the circuit can feed (`fits_1yr`).
10. Bias from unflagged faults (lines 839-850): 9.5% of shots carry a fault. A late fault on a fermion qubit adds at most 0.119 quanta per mode in the worst shell (`fermion_fault_shift`, lines 1086-1122). The resulting bias is 11% at $n_k = 0.1$, 2.3% at 0.5 and 1.1% at 1 (`fault_bias_fermion`). One shot also holds $1.56\times10^{12}$ idle qubit-cycles, 105 times $N_T$ (`idle_qubit_cycles`).

### What fixes the step and the grid (lines 1063-1625)

These functions do not enter the cost arithmetic. They justify the inputs it uses, and the tests rerun short versions of each.

- 2033 step: `verlet_proxy` runs the circuit's kick-drift-kick map on the condensate, the linear scalar fluctuations and the free fermion modes. On fermion shells with $n_k > 0.1$, $m_\phi\Delta t = 1$ fails and $0.05$ gives at most 1.6% (`proxy_step_err_2033`; `test_step_proxy_rejects_omega_dt_1_and_accepts_0p05`). `exact_reduced_step` runs the exact splitting on a 3-site ring at $K = 16$ with one Wilson fermion, giving at most 0.31% step error (`exact_step_err_reduced_2033`). That is at most 1.23 times the proxy (`exact_over_proxy_step_2033`), or 2% when scaled to $5^3$ (`step_err_extrapolated`). The same run shows that a field grid fixed at $a(t_{\rm in})$ fails (30% error at $m_\phi t = 50$), so the register holds $\chi = a^{3/2}\phi$. Its squeeze is absorbed into angle changes on existing rotations, checked by `enc="shear"` against the explicit squeeze (`test_shear_encoding_matches_explicit_squeeze`).
- Constructor guards (lines 426-444): the 2033 step must satisfy $m_\phi\Delta t \le 0.05$, and both the step and the ramp step must stay inside the Stormer-Verlet window $\omega\Delta t < 2$.
- 2028 grid: `ds2028_grid_check` evolves the digitized free field exactly on a 4-site ring. With the grid refit every step, $K = 8$ holds every shell to 0.10-0.14% after one step for $m \approx 1$-$1.5\,H_{\rm inf}$ (`grid_2028_k8_one_step`). `ds2028_map_vs_exact` shows that the one-step map itself is 13-25% from exact de Sitter at $m = 1$-$1.4\,H_{\rm inf}$ (28% at 1.5; `map_vs_desitter_2028_one_step`), which is why the validation target is the map and not de Sitter.
- Register capacity: `digitized_site` and `coherent_fidelity` show that $K = 16$ holds a condensate of about two quanta per site (`condensate_quanta_per_site` = 1.99).
- Classical comparator: `twopi_lo`, a Gaussian truncation, reaches the late fermion $n_k$ to 5.3% on the reduced instance (`twopi_lo_fermion_err_late`). That is why the chapter calls the $5^3$ instance a cross-check rather than an advantage claim.

## 7. Open items and limitations

From `docs/OPEN_ITEMS.md` and the model's list of what it does not derive:

- The 2028 vacuum preparation (30,000 T) is stated, not derived. The cap leaves $10^5 - 64{,}753 = 35{,}247$ T for it (`hard_op_cap` minus `t_evolution`); a compiled network costing more than that would push the single step over $10^5$.
- Not priced at 2033:
  - the free vacuum the ramp starts from, about $7.5\times10^4$ T at 150 T per scalar qubit (model docstring), $5\times10^{-6}$ of the $1.49\times10^{10}$-T shot;
  - the fermion out-basis readout, at most $7.4\times10^6$ T (`t_fermion_readout_bound`), $5\times10^{-4}$ of the shot;
  - the preparation-only vacuum reference run, 2.4% of a shot (`vacuum_reference_fraction`);
  - the scalar conjugate-basis readout QFT, $4.2\times10^4$ T (`t_qft_readout`);
  - the 50-step $\Delta t$ sweep between ramp and evolution, $3.6\times10^7$ T, 0.24% of the shot (`t_dt_sweep`).
- The 2033 step rests on a mean-field proxy and an exact check on a 3-site ring with one fermion. The full 3D case and the Pauli-string split of the hop are not tested.
- The 2033 shot is 14.9 times the $10^9$ budget and needs $\epsilon_l \lesssim 7\times10^{-12}$, three orders below the RFI figure. Splitting the shot does not help, because the evolved state carries its accumulated faults. This instance is a co-design target.
- The fault budget counts T gates only. Idle storage ($1.56\times10^{12}$ qubit-cycles per shot) would dominate at the same rate per location, and early faults are not bounded. With no detection model a faulted shot is kept and biases $\langle n_k\rangle$ (Section 4, item 10).
- What $K = 16$ holds limits the condensate amplitude to about $0.3\,m_\phi$. The scalar shells then sit below $n_k = 0.06$ and are read to only 46-65% at the priced shots (`scalar_eps_at_priced_shots`), so the 10% target applies to the fermion shells with $n_k \gtrsim 0.05$ (`fermion_n_min_priced`).
- At the proxy couplings a Gaussian truncation already reaches the late fermion spectrum to 5.3%. A quantum advantage would need stronger per-site coupling or the scalar shells, which the truncation misses by up to 66%.
- The 2028 one-step map is 13-25% from exact de Sitter at $m = 1$-$1.4\,H_{\rm inf}$, and lighter fields fail over more steps: at $m = H_{\rm inf}$, $K = 8$ is off by 0.26 after four steps (note on `grid_2028_k8_adapted_end`; `test_2028_grid_check` asserts it exceeds 0.1). The benchmark validates the circuit against its own map, for $m \approx 1$-$1.4\,H_{\rm inf}$.
- The 2028 T-depth (346-1308) comes from the factory schedule of a $K=4$, four-step circuit and was not recomputed for the $K=8$ one-step circuit, which has fewer rotation layers on its busiest qubit (36 against 57). $F^*$ stays far above 10 either way.
- The lattice spacing $b \approx 3.5/m_\phi$, the background $a(t) \propto t^{2/3}$ without backreaction, $N_{\rm anc} = 30$-$50$, and the choice of the 10-20 campaign profiles are inputs, not derived.
- Hamming-weight phasing would cut rotation T to 0.53 (2028) or 0.42 (2033) of plain synthesis (`hwp32_t_over_plain`), at 31 workspace qubits per 32-rotation group. It is not taken: the 2028 shot fits without it, and the 2033 register has no room for it.

## 8. Conventions used

This chapter uses the report-wide conventions described in the [top-level README](../../README.md) and implemented in `estimates/common.py`. Rotations are priced at the full repeat-until-success fit, $1.15\log_2(1/\epsilon) + 9.2$ T, with $\epsilon$ set per shot by R-TOL ($10^{-2}$ total synthesis error). Toffolis are priced at 7 T, though none appear here; the controlled-S gates are priced at 3 T directly. The fault budget is 0.1 expected logical faults per shot in the T gates. Wall time is for one machine, serial: 1 µs per T plus 0.1 ms per shot, with the T-depth check $F^* \ge 10$ for the ten-factory baseline. The DOE reference budgets ($10^5$ T for 2028, $10^9$ T for 2033) are comparison points.
