# Chapter 5: transport in the quark-gluon plasma

Model: `estimates/ch05_qgp_transport.py`. Tests: `estimates/tests/test_ch05_qgp_transport.py`. Chapter: `applications/app03_qgp_transport.tex` in the paper.

Every number below is printed by the model, written to `resources.json`, or pinned by a test, and the text names which. "Line" references are to `estimates/ch05_qgp_transport.py` unless another file is named.

## 1. What is estimated

The observable is the shear-channel autocorrelator of the momentum-projected stress tensor, A_k(t) = ∫ d³x sin(k x₃) T⁰¹(x, t), measured in real time on a thermal state. Its decay at small k is the transverse-momentum diffusion that defines η/s. The chapter's lattices are far too small for the hydrodynamic limit, so what is priced is a finite-volume correlator and a decay rate Γ(k_min) at the smallest lattice momentum, as method validation.

- **2028 benchmark.** 2+1D pure-gauge SU(2) replaced by its binary tetrahedral subgroup 2T (|G| = 24, 5 qubits per link), Kogut-Susskind Hamiltonian, 4² lattice at a_s = 0.2 fm, a_t = 0.1 fm/c. T = 1.5 T_c = 739.2 MeV (`T_2028_MeV`) and k = 2π/L⊥ = 1.55 GeV = 2.1 T (`k_2028_GeV`, `k_over_T_2028`). Two tiers: a first result (t = 0 and one Trotter step of 0.045 fm/c) and a full benchmark (seven timeslices, six steps of a_t/4 to 0.15 fm/c). The initial state is not priced: this is a non-thermal placeholder for the kernel.
- **2033 target.** Σ(216×3) ⊂ SU(3) (|G| = 648, 11 qubits per link) with the improved Hamiltonian H_I and three staggered fields (N_f = 4+2 tastes), on 3³ at a_s = 0.2 fm (L = 0.6 fm). The temperature is T = 1.5 T_c^lat, with the crossover T_c^lat of the simulated theory assumed to lie in 150-200 MeV, so T = 225-300 MeV (`T_2033_MeV`). Each shot is one circuit: a quench that prepares the thermal state, then real-time evolution to one of two fit times. The first result is Γ(k_min) at μ_B = 0 to 30%; the campaign is Γ(k_min) to 20% on a 4×4 (T, μ_B) grid at two lattice spacings. k_min = 2.07 GeV = 6.9-9.2 T (`k_min_2033_GeV`, `k_min_over_T_2033`).
- **Co-design row.** Not a box (a "box" is the chapter's printed resource summary for the 2028 or 2033 target). The `codesign` era prices the 400-step (4 fm/c) reference evolution with the chapter's conjectured qubitized block encoding at a stated 10x trim: 1.444e9 T per shot (`t_per_shot_codesign_be`). It writes no row to `resources.json`.

## 2. How to run

From the repository root:

```
python -m estimates --chapter ch05                     # assumptions, resources.json rows, per-era exports
python -m estimates --chapter ch05 --intermediates     # adds every recorded intermediate
python -m pytest estimates/tests/test_ch05_qgp_transport.py -q
python applications/ch05_qgp_transport/dump_assumptions.py   # the table in section 3
```

The chapter report prints three blocks. ASSUMPTIONS lists the 90 input fields with value and provenance (cited 19, assumed 27, stated-not-derived 44). INSTANCES shows the three rows the chapter writes to `resources.json`. EXPORTS shows, per era, logical qubits and hard operations against the printed box (`[ok]` when they agree within the box tolerance of 5%), shots, wall time, the required ε_l, the depth and factory exports, and the per-primitive T breakdown of the deepest shot.

The chapter test file gives `43 passed, 199 skipped` in this repository. The skips compare model numbers with the chapter text and run only when the paper source sits beside the package.

## 4. How the numbers are built

The cost factorizes into a register, a T-count per shot, a shot count and a wall time. Each step below names the function that does it. Keys in backticks are `Result.intermediates` entries, printed by `--intermediates`.

### 4.1 Logical qubits

`lq_range` (lines 517-520) implements the chapter's Eq. (Nq), N_q = d L^d q_G + N_c N_stag L^d + N_anc, with q_G the register width of the group's compiled primitive set (`groups.py`).

- 2028: 32 links × 5 = 160 gauge qubits, plus 1-2 Hadamard-test ancillas, plus 16 primitive workspace qubits (`workspace_2028`, added in `_model_2028`, lines 941-1092): 177-178. The workspace lets eight U_FFT (two ancillas each) run at once so that ten factories stay busy: F* = N_T / D_T per step (T-count over T-depth, the number of factories a step can keep busy) is 10.66-57.07 with it (`f_star_2028_per_step`) and 1.66 with only the two qubits any primitive needs (`f_star_2028_at_2_workspace`).
- 2033: 81 links × 11 = 891 gauge, 3 colors × 3 fields × 27 sites = 243 fermion, plus 100-200 ancillas: 1234-1334 (`lq_2033_lo`, `lq_2033_hi`).

### 4.2 T per link per Trotter step

`link_step_primitives` (lines 622-660) takes each gate primitive of the group from `groups.py`, multiplies it by its count per link per step for the chosen Hamiltonian (`PRIMCOST`, `groups.py` lines 132-135), and prices it as

  T_p(ε) = a_p + n_p (1.15 log2(1/ε) + 9.2),

where a_p is the Clifford+T part (7 T per Toffoli plus any exact T) and n_p is the number of synthesized rotations, the source paper's log2 coefficient divided by 1.15 (`groups.PrimitiveCost`). Multiplicities per link per step are U_F 2, U_Tr (d-1)/2, U_inv 3(d-1), U_mul 6(d-1) for H_KS, and U_F 4, U_Tr 3(d-1)/2, U_inv 2+11(d-1), U_mul 4+26(d-1) for H_I; the Σ(216×3) electric phase U_Ph is called twice per link-step at H_I (`phi_mult`, lines 542-545).

| primitive | term | 2T, H_KS, d = 2: count | 2T: a + n | Σ(216×3), H_I, d = 3: count | Σ(216×3): a + n |
|---|---|---|---|---|---|
| U_mul | magnetic | 6 | 154 (22 Toffoli) + 0 | 56 | 2548 (364 Toffoli) + 0 |
| U_inv | magnetic | 3 | 28 (4 Toffoli) + 0 | 24 | 2065 (295 Toffoli) + 0 |
| U_Tr | magnetic | 0.5 | 0 + 11 | 3 | 30786 (4398 Toffoli) + 14 |
| U_FFT | electric | 2 | 98 (14 Toffoli) + 42 | 4 | 1086 + 460 |
| U_Ph | electric | - | - | 2 | 630 (90 Toffoli) + 10 |

Sources: 2T from arXiv:2208.12309 (U_mul, U_inv, U_Tr) and arXiv:2408.00075 (U_FFT); Σ(216×3) from the draft in preparation `Gustafson_S648_inprep`.

- 2028, at the six-step shot's ε = 7.628e-4 (21.11 T per rotation): magnetic 1124.1 + electric 1969.2 = 3093.3 T per link-step (`magnetic_t_per_link_step_2028`, `electric_t_per_link_step_2028`, `t_per_link_step_2028`), 98,986 T per step over 32 links.
- 2033 gauge, at the 400-step reference shot's ε = 7.989e-6 (28.67 T per rotation): magnetic 2.858e5 + electric 5.894e4 = 3.447e5 T per link-step (`gauge_t_per_link_step_2033`).

The 2033 target also has fermions, priced from the unpublished Fermion_Primitives draft (`FermionPrimitives_unpub`):

- **Staggered hop**, `hop_link` (lines 564-569) calling `groups.hop_link_cost`. No hop circuit exists for Σ(216×3), so the Σ(72×3) counts stand in (`hop_group_2033`, a placeholder). Per link-step: 3,672 Toffoli + 360 T + 2,933 rotations, 1.1016e5 T at the reference ε (`hop_t_per_link_step_2033`). The pieces (`hop_items_t_per_link_step_2033`): color squish and parity flags, computed once per link and held through the frame changes, 3,330 Toffoli (23,310 T); color-frame rotations, 4 frame applications × 3 fields × 184 = 2,208 rotations (63,311 T), of which the inverse-frame half is estimated here because the draft draws it but does not count it (31,656 T, `hop_undo_t_per_link_step_2033`); hop squish and flags, 326 Toffoli (2,282 T); 180 controlled diagonalizers, 360 T + 720 rotations (21,005 T); one Hamming-weight phasing group of 18 equal-angle rotations, 16 Toffoli + 5 rotations (255 T).
- **Staggered mass**, `mass_site` (lines 578-581) calling `groups.staggered_mass_site`: the 9 equal-angle R_Z on a site as one Hamming-weight phasing group, 4 rotations + 7 Toffoli = 163.7 T per site-step (`mass_t_per_site_step_2033`). A baryon chemical potential adds the same angle and costs nothing extra.

In all, 4.550e5 T per link-step and 3.685e7 T per step (`t_per_link_step_2033`, `t_per_step_2033`); the hop is 24.2% of the step and the mass 0.012% (`hop_share_of_step_2033`, `mass_share_of_step_2033`).

### 4.3 Rotation tolerance

`rotations_per_link_step` (lines 603-619) counts synthesized rotations per link-step: 0.5 × 11 + 2 × 42 = 89.5 for 2T, and 1902 gauge (3 × 14 + 4 × 460 + 2 × 10) + 2933 hop + 4/3 mass (4 per site, 3 links per site) = 4836.33 for 2033. A shot of S steps has N_rot = n × links × S, and `common.eps_rot_for` (`common.py` line 172) sets ε = sqrt(10⁻² / N_rot), so the randomized-synthesis error per shot totals 10⁻². Every circuit gets its own ε: the six-step 2028 shot has 17,184 rotations and ε = 7.628e-4; the one-step shot ε = 1.869e-3 (`eps_per_slice_2028`); the 2033 deepest shot (604 steps) ε = 6.501e-6 and 29.02 T per rotation (`eps_rot_fit_points`, `t_rot_fit_points`). The per-link-step figures of 4.2 for 2033 are quoted at the reference ε; the box prices each shot at its own. `test_rtol_rotation_count_is_complete_by_perturbation` re-prices the evolution at two tolerances and checks that the change is exactly N_rot × 1.15 log2(ε₁/ε₂), so no rotation is left out of N_rot.

### 4.4 Steps per shot

**2028** (`evolution_2028`, lines 667-678; `tiers_2028`, lines 774-795). Timeslice j = 0..6 is a circuit of j steps with T_j = 32 × per-link-step(ε_j) × j: T_1 = 9.473e4 and T_6 = 5.939e5 (`t_per_slice_2028`). The step a_t/4 = 0.025 fm/c holds the state-dependent second-order Trotter error estimate to 0.083 over six steps (`trotter_2028_sd_err_full`); the first result's single step of 0.045 fm/c gives 0.081 (`trotter_2028_sd_err_first`). The gate count of a step does not depend on Δt.

**2033** (`own_depth_2033`, lines 816-934). A shot is the quench preparation followed by the fit evolution, priced as one circuit at its own ε by `evolution_2033` (lines 681-692).

- Preparation (`quench_steps`, lines 807-813): a coupling ramp of one a_s, ceil(a_s / Δt) = 20 steps at Δt = a_t/10 = 0.01 fm/c, then thermalization for t_th = c/T with c ∈ [2, 2π]: 132 steps at c = 2, T = 300 MeV, and 552 steps at c = 2π, T = 225 MeV (`quench_th_steps`). In all 152-572 steps (`quench_prep_steps`).
- Fit times: the assumed decay time τ runs from 1/k_min = 0.0955 fm/c to 1/(2πT) = 0.1396 fm/c at 225 MeV (`tau_band_fm`). The two fit points sit at Γt = 0.5 and 1.8, rounded up onto the 0.01 fm/c grid: 5 and 18 grid steps at the fast end, 7 and 26 at the slow end (`fit_steps_grid`).
- Step rule: a fit shot runs max(N_grid, ceil(sqrt(Λ_sd t³ / ε))) steps, t in units of a_s and ε = 0.1, where Λ_sd = 45.79 a_s⁻³ is the free-field state-dependent second-order estimate on the H_I dispersion (`trotter_state_dependent`, lines 1583-1598; `lambda_sd_corners`). It binds only on the late shots, 18 → 19 and 26 → 32 (`fit_steps`). This is an estimate, not a bound: the worst-case commutator bound would need 481 and 835 steps for those shots (`trotter_worst_steps_deepest`).
- Corners: the band pairs the cheap ends (T = 300 MeV, τ = 1/k, c = 2) and the expensive ends (T = 225 MeV, τ = 1/(2πT), c = 2π). The other six corners of (T, τ, c) are recorded (`t_deepest_corners`, `first_result_corners`).

Deepest shot at a_s = 0.2 fm (`test_2033_own_depth_per_shot_and_eps_l`):

| | cheap corner | expensive corner |
|---|---|---|
| preparation steps | 152 | 572 |
| fit steps | 19 | 32 |
| ε per rotation | 1.222e-5 | 6.501e-6 |
| preparation T (`quench_prep_t`) | 5.560e9 | 2.116e10 |
| fit-evolution T (`t_fit_deepest`) | 6.949e8 | 1.184e9 |
| shot T (`t_deepest`) | 6.255e9 | 2.234e10 |

The preparation is 8.0-17.9 times the fit evolution (`quench_prep_over_fit`), and the shot is 6.3-22.3 times the 10⁹ reference budget (`ratio_deepest_to_budget`). The CLI's primitive breakdown is the expensive-corner shot: 604 steps × 81 links = 48,924 link-steps (`_own_breakdown`, lines 1366-1371).

The second spacing (`second_spacing_assumptions`, lines 798-804) keeps the 3³ lattice at a_s = 0.15 fm and scales a_t with a_s, so Δt ‖H‖ is held. Its preparation is 196-755 steps, its fit shots (5, 19) and (10, 48) steps (`second_spacing_own_step_fit_steps`), and its late shot 7.880e9-2.977e10 T (`t_deepest_campaign`), the deepest of the campaign.

### 4.5 Shots

- 2028: stated at 10³ per timeslice, so 2×10³ for the first result and 7×10³ for the full benchmark. No precision target is attached (section 7).
- 2033: `fisher_shots` (lines 760-771). Each shot is a ±1 Hadamard-test outcome with mean μ = C̄ e^{-x}, x = Γt, and variance 1 − μ². A fraction f = (0.2, 0.8) of the shots sits at the two fit points, and the amplitude c₀ and Γ are both free. With the Fisher matrix I_ab = Σ_i f_i ∂_a μ_i ∂_b μ_i / (1 − μ_i²) over (c₀, ln Γ), the shots for relative error r on Γ are N = [I⁻¹]_{ln Γ, ln Γ} / r². At C̄ = 0.16 (`cbar`, the assumed normalized correlator, the mean of the ±1 estimator at t = 0) the first result (r = 0.3) needs 1.600e4 shots at the cheap corner and 1.530e4 at the expensive one (`shots_first_result`). The campaign (r = 0.2) needs 3.599e4 / 3.443e4 per point (`shots_per_point_campaign`), times 16 points per spacing and two spacings: 1.152e6 / 1.141e6 in all (`shots_campaign`).

### 4.6 Depth, factories and wall time

Per-step T-depth (low, high) comes from the factory schedule: `step_depth_2028` (lines 704-720, with the 16 workspace qubits) and `step_depth_2033` (lines 723-757). The 2033 schedule was built for H_KS and is scaled to H_I by each primitive's multiplicity ratio, a step derived here. A shot's depth is its step count times the per-step depth. Each shot is charged max(N_T × 1 µs, D_T,high × 10 µs) + 0.1 ms, serially on one machine. Every shot has F* = N_T / D_T ≥ 10 (about 10.7 at 2028 and 34.7-35.1 at 2033, `f_star_fit_points_hi`), so the T-count term always wins and the wall is shots × (N_T × 1 µs + 0.1 ms).

- 2028: first result 10³ × 0.1 ms + 10³ × (9.473e4 × 1 µs + 0.1 ms) = 94.93 s; full benchmark summed over the seven slices, 2059 s = 34.3 min.
- 2033: first result N_first Σ_i f_i (T_i × 1 µs + 0.1 ms) = 3.118 yr (cheap) to 10.74 yr (expensive) (`wall_first_result_yr`), and 3.12-11.02 yr over all eight corners. Campaign, two spacings of 16 points: 254.1-937.7 yr (`campaign_two_spacings_yr_own`), 50.8-187.5 times the 5-year horizon (`campaign_reduction_needed_own`); one 20% grid point takes 7.0-24.2 yr (`grid_point_yr_own`). The in-situ T_c^lat scan (10 ramp energies × 100 preparation-only shots) adds 0.18-0.67 yr, about 6% of the first result (`tc_diag_wall_yr`, `tc_diag_over_first_result`).

`common.depth_exports` (`common.py` line 316) turns a shot-averaged T-count, T-depth and shot count into the contract exports: f_star = N_T / D_T (cross-paired), floor_wall_s = shots × D_T × 10 µs (the shortest run any number of factories allows), and factories_for_1yr = 10 × shots × N_T × 1 µs / 1 yr.

### 4.7 Required logical error rate

ε_l = 0.1 / N_T of the deepest shot (0.1 expected faults per shot): 1.599e-11 at the cheap corner and 4.476e-12 at the expensive one (`eps_l_deepest`), 3.359e-12 on the second spacing's late shot (`eps_l_deepest_campaign`). The 2028 era exports none.

## 7. Open items and limitations

From `docs/OPEN_ITEMS.md` and the chapter's algorithm-development gap list. None of these changes a printed number until it is resolved.

- **Temperature.** The crossover T_c^lat of the simulated theory is unknown; 150-200 MeV is assumed (`Tc_lat_2033_MeV`), so every 2033 range carries a 300 MeV and a 225 MeV corner. The in-situ scan locates the crossover in ramp energy, and placing the campaign at 1.5 T_c^lat still needs an energy-to-temperature map.
- **Thermal preparation.** The quench assumes eigenstate thermalization at these couplings on 3³, t_th = c/T with c in [2, 2π], a one-a_s ramp as a floor, relaxation of the momentum density within t_th, and the thermal variance. All are checked only on small, exactly solvable lattices. The preparation is 8-18 times the fit evolution and puts every 2033 shot 6-22 times over the 10⁹ budget. It runs at the 0.01 fm/c grid step; a coarser preparation step (`docs/OPEN_ITEMS.md` suggests 2-5x) is an unpriced lever.
- **Group and action.** A non-freezing H_I trajectory for Σ(216×3) at 0.15-0.2 fm is assumed by analogy with Σ(360×3), not established; the fallback Σ(360×3) costs 81 more qubits on 3³ (`sigma360_extra_lq`). The Σ(216×3) primitives come from a draft in preparation.
- **Fermion hop.** No hop circuit exists for Σ(216×3); the Σ(72×3) placeholder is 24% of the step, and Σ(216×3) has 24 classes against 16, so the true hop is likely larger; doubling it would grow the step by about its 24% share (`hop_share_of_step_2033`). Recomputing the color squish at every frame change gives 1.715e10 T for the reference shot (`t_per_shot_2033_mu0_evolution_share_draft`); whether the inverse-frame undo (3.17e4 T per link-step) is needed is open.
- **Trotter step.** The step is set by a state-dependent estimate, not a bound; see 4.4. The 400-step reference shot to 4 fm/c is a pricing basis only; the same rule would need 1914 steps for it (`trotter_sd_steps_ref`).
- **Fit design and shots.** Which early transient the fit drops is not derivable from the inputs: fitting from t = 0 takes 0.37 times the shots, dropping Γt < 1 takes 2.7 times (`design_A_over_B`, `design_C_over_B`). C̄ = 0.16 is carried without the block encoding of A_k that would fix it. A third fit time to confirm a single exponential is not priced. The decay band 1/k to 1/(2πT) is not conservative at the slow end.
- **Campaign.** 254-938 yr, 51-188 times the horizon, a stated co-design gap with no priced lever. The second spacing sits on the same 3³ lattice, so volume and k_min change with a and the two spacings do not give a continuum limit at fixed physics; holding L = 0.6 fm needs 4³ and 2788-2888 qubits (`fixed_volume_4cubed_lq`).
- **2028 shot count.** 10³ per timeslice has no set precision. At 30% with an assumed fall-off of 0.1 over the 0.045 fm/c step it is 8.46e4 shots and 1.1 h (`shots_first_result_2028_at_30pct`, `wall_first_result_2028_at_30pct_h`); since the correlator is even in t the fall-off is closer to 0.02, which would raise the count (0.1/0.02)² = 25 times, using the ~0.02 in the `first_result_falloff_2028` note. The full benchmark needs a ≥5.94x per-step cut; the named levers are assumed at 3-10x and only the upper part closes it. The 2028 instance prices no thermal state; a quench would add 3.2e6-8.1e6 T (`quench_first_result_shot_2028`).
- **Physics reach.** At L = 0.6 fm, m_π L ≈ 0.9-1.2 and k_min ≈ 7-9 T: Γ(k_min) is not η/s. m_π L ≥ 4 needs a 12³ lattice and 72,676-72,776 qubits (`lq_12cubed_lo`, `lq_12cubed_hi`), 2.0 times the LANL estimate, and k_min ≤ T needs L ≈ 4.1-5.5 fm (`L_for_kmin_eq_T_fm`). O(a²), finite-volume and subgroup-truncation systematics are not derived and are not printed as error bars. The average sign on this box is not computed, so the classical-comparator verdict at μ_B > 0 is prospective.

## 8. Conventions used

Toffoli = 7 T; every rotation at the full synthesis fit 1.15 log2(1/ε) + 9.2 T with ε set per circuit so the total synthesis error is 1%; 0.1 expected faults per shot fixes ε_l; wall times are serial on one machine at 1 µs per T and 0.1 ms per shot, about ten factories; logical-qubit counts exclude the factories. These are defined once in the top-level `README.md` and in `estimates/common.py`, and this chapter follows them without exception.
